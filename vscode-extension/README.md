# Antigravity AI Agent VS Code Extension

This extension integrates the Antigravity Agent Dashboard directly inside VS Code as a sidebar/editor panel.

## Features
- **Auto Server Boot**: Launches the Python `gui_server.py` in the background automatically when you open the dashboard.
- **Embedded Webview**: Shows the premium dark-mode, glassmorphism dashboard inside a native VS Code panel.

## Usage
1. Open your project folder in VS Code.
2. Open the Command Palette (`Ctrl+Shift+P` or `F1`).
3. Search and select: **`Antigravity Agent: Open Dashboard`**.
4. The agent dashboard will open in a new tab inside VS Code!
